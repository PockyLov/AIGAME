# Original Game Art and IP Safety Skill

## Scope

Use this skill for:
- Game title.
- Character design.
- Enemy design.
- Collectible design.
- World theme.
- UI style.
- Music and sound direction.
- Asset license review.
- Similarity review against Mario/Nintendo-like elements.

## Forbidden Elements

Do not use:
- Mario, Super Mario, Nintendo, Luigi, Peach, Bowser, Mushroom Kingdom, Goomba, Koopa, or confusingly similar names.
- Red-hat plumber protagonist.
- Mushroom power-up design.
- Green pipe visual identity.
- Question-mark block lookalike.
- Directly copied coin, brick, enemy, map, music, sound, logo, or sprite designs.
- Unlicensed commercial assets.

## Preferred Original Direction

Use original themes such as:
- Clockwork forest.
- Star fragment ruins.
- Tiny robot explorer.
- Paper world.
- Cloud workshop.
- Crystal cave.
- Toy factory.
- Lantern valley.

Possible original collectibles:
- Star shards.
- Energy sparks.
- Crystal seeds.
- Memory chips.
- Glow bells.

Possible original enemies:
- Patrol bots.
- Wind-up beetles.
- Slime blobs.
- Rolling stones.
- Spark drones.

## Required Checks

Before approving art or naming:
- Is the name original?
- Does the protagonist avoid Mario-like appearance?
- Do enemies avoid Goomba/Koopa similarity?
- Are collectibles visually distinct from Mario coins?
- Are blocks and platforms visually distinct?
- Are all external assets license-safe?

## Response Format

Report:
1. Similarity risk: low / medium / high.
2. Specific risky elements.
3. Replacement suggestions.
4. Approved original direction.
5. Asset license notes.
