# AIGAME Project Brief

## Goal

Build an original 2D side-scrolling platformer web game.

Final target:
- A user can open it in a desktop browser.
- A user can play with keyboard.
- The project can be handed off to another computer.

## MVP Features

- Player movement.
- Jumping.
- Gravity.
- Collision.
- Platforms.
- Collectibles.
- Enemy.
- Death/restart.
- Finish goal.
- First complete level.
- README.

## Original Creative Direction

Working direction:
- Original platformer world.
- No Mario/Nintendo names or assets.
- Placeholder shapes are acceptable in MVP.
- Final art direction can be decided after the game becomes playable.

Possible theme:
- Tiny robot explorer in a clockwork forest.
- Collect energy sparks.
- Avoid patrol bots.
- Reach a glowing exit gate.

## Delivery Requirement

The final project must support:
- Local development run.
- Production build.
- Browser-based play.
- Keyboard control.
- Clear README handoff.
