# UI/UX Skill

Use this skill when changing menus, HUD, instructions, pause, game over, or level clear screens.

## Checklist

- Show essential controls in game and in README.
- Keep menu labels short and action-oriented.
- Support keyboard navigation for desktop play.
- Provide clear failure and completion messages.
- Avoid complex menu systems during MVP polish.

## Done When

- Player can start, pause, resume, restart, return to menu, and read how to play.
- Game over and clear screens explain what happened.
- HUD text remains readable in the Tauri window.
