# Mobile Adaptation Skill

Use this skill when improving mobile browser readability and basic touch play for the static Web playable. This skill does not authorize Android APK, iOS, app store, or native mobile work.

## Checklist

- Keep desktop keyboard controls intact.
- Design touch controls separately from desktop keyboard controls.
- Verify canvas scaling on small screens.
- Keep touch controls below the game area when possible so they do not cover core play.
- Add a portrait orientation hint when landscape play is clearer.
- Avoid adding large dependencies for mobile browser support.

## Forbidden During Phase 10

- No Android APK.
- No iOS.
- No native mobile release work.
- No backend services.

## Done When

- Mobile users can see the canvas.
- Portrait users see a landscape hint.
- Touch users have left, right, jump, and pause controls.
- Desktop keyboard play still works.
