# QA Report Skill

Use this skill when preparing phase reports or final delivery notes.

## Required Report Sections

- Stage Goal
- Changed Files
- Added Features
- Preserved Behavior
- Commands Run
- Test Results
- Known Issues
- Risk Notes
- Next Phase Recommendation

## Checklist

- Include exact command names.
- Mark each command pass or fail.
- Explain failed commands and whether they are code or environment issues.
- Do not claim GUI or gameplay verification unless it was performed.
- Keep release artifact paths specific.
