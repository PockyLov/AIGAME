Do not download or share raw dist, target, MSI, or intermediate build folders. The current installer is generated locally; uploading it to GitHub Releases is a future publishing step.

Game

What it is

Start from the in-game menu, collect energy sparks, avoid patrol bot side hits, and reach each glowing exit gate.

Current content includes three short levels, pause/restart flows, generated sound effects, and simple original canvas art.

Controls

Controls

Keyboard: Arrow keys or A/D to move, Space/W/Up to jump, P/Esc to pause, R to restart.

Mobile browser: rotate sideways, then use the on-screen Left, Right, Jump, and Pause buttons.

Platforms

Status

Web is playable through a static page. Windows can be packaged with Tauri. Android is still environment exploration. iOS has not started.

Known Limits

Alpha scope

Android APK is not generated yet. iOS is not supported. There are no accounts, leaderboards, cloud saves, payments, or backend services.

Mobile browser play still needs more real-device testing.

Originality

Asset note

AIGAME uses original canvas-drawn placeholder geometry and generated sound effects. No commercial game sprites, music, maps, or protected names are used.
